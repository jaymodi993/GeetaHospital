# Geeta Multi-Speciality Hospital Mundra (Kutch)

> Leading 45-Bed Multi-Speciality Hospital in Mundra & Kutch since 2009. ISO 9001:2015 Certified & ROHINI Registered.

Recreated with modern web standards: **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, **TypeScript**, and **Senior-Level Healthcare SEO**.

🌐 **Live Reference:** [https://geetahospitalmundra.com](https://geetahospitalmundra.com)

📞 **24x7 Emergency Hotline:** +91 78743 81551

## 🚀 Key Highlights & Tech Stack

- **Framework:** Next.js 16.4.6 with Turbopack & React 19
- **Styling:** Tailwind CSS v4 + Lucide React + Framer Motion animations
- **TypeScript:** Strict type-safety across all data contracts and props
- **Performance:** 100% static prerendering with sub-second page loads
- **Doctor Profiles:** Verified 1-to-1 doctor names, credentials, and authentic photography extracted from original hospital records
- **SEO & Structured Data:** Full Schema.org JSON-LD integration (`Hospital`, `MedicalBusiness`, `EmergencyService`, `Physician`, `FAQPage`, `BreadcrumbList`)
- **Assets:** High-resolution local image assets for instant loading and reliability

## 🏥 Hospital Overview & Facilities

- **Bed Capacity:** 45-Bed Multi-Speciality setup across ~9,500 sq. ft.
- **Critical Care:** 3-Bed Adult ICU with mechanical ventilators & 5-Bed Neonatal ICU (NICU) with incubators
- **Surgical Suites:** Modular Gynecological OT with laparoscopy tower & Orthopedic OT with IITV C-ARM image intensifier
- **24x7 Services:** Emergency Room, ICU Ambulance, In-House Pathology Laboratory, and In-House Pharmacy (Geeta Medical Stores)
- **Diagnostics:** 3D/4D Color Doppler USG, Digital Radiography (X-Ray), and 12-Lead ECG
- **Inpatient Care:** 1 Deluxe Suite, 7 Special AC Rooms, 3 Semi-Special AC Rooms, and separate Male & Female General Wards

## 🛠️ Getting Started Locally

```bash
# Clone repository
git clone https://github.com/jaymodi993/GeetaHospital.git
cd GeetaHospital

# Install dependencies
npm install

# Run development server
npm run dev

# Run production build
npm run build

# Start production server
npm run start
```
